# Instruções para Agentes

## Regra Obrigatória: Commit e Push

**Toda alteração feita nos arquivos DEVE ser commitada e enviada (push) ao repositório remoto.**

### Procedimento padrão após cada alteração:

1. `git add .` - Adicionar todas as alterações
2. `git commit -m "descrição da alteração"` - Criar um commit com mensagem descritiva
3. `git push` - Enviar as alterações ao repositório remoto

### Regras:

- NUNCA deixe alterações sem commitar
- NUNCA faça alterações sem dar push ao final
- Mensagens de commit devem ser claras e descritivas em português
- Sempre execute os 3 passos acima ao finalizar qualquer tarefa de edição
